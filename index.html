Your files.

A personal desktop utility for transferring selected files between a Windows computer and the owner's Google Drive account.

在自己的 Windows 电脑与 Google 云端硬盘之间上传、下载和校验选定的文件。

Read the privacy policy ↗
01

Choose a file

The owner runs a local PowerShell command and chooses a file to upload. Transfers use rclone and the Google Drive API.

02

Authorize access

Google OAuth connects the owner's account. The utility requests drive.file: access to files it creates or files explicitly made available to it.

03

Keep control

Files stay in the owner's Drive and can be downloaded or verified locally. The owner controls sharing, deletion and account access.

About this application

Magic Drive Backup is maintained by lu1434417495-sys for personal use. This website provides application and privacy information; the file-transfer utility runs on the owner's computer.

Google Drive access is used to create backup files, read relevant file metadata, and retrieve those files. Access remains limited by the drive.file permission. This utility is independently maintained and is not a Google product.

For questions, use the developer contact shown on the Google authorization screen or the project's contact page. Please do not post private files or credentials in public issues.
